# ClimateAction 🌱

**Live Site:** [https://d3mio.github.io/ClimateAction/](https://d3mio.github.io/ClimateAction/)

A static, multi-page web application dedicated to promoting environmental awareness and climate action initiatives. This project was collaboratively built to showcase various aspects of climate change, volunteer opportunities, and team insights.

## 🚀 Tech Stack

- **HTML5:** Semantic and accessible page structure.
- **CSS3:** Custom styling and responsive design.
- **Vanilla Web Development:** Built without heavy frameworks to ensure maximum performance, accessibility, and fundamental web development practices.

## 📂 Project Structure & Methodology

The project adopts a modular, collaborative structure divided among four student developers, with a unified entry point that links the entire project together.

### Unified Entry Point
- `index.html`: The main entry file serving as a central hub (loads the splash screen).
- `css/`: Shared and specific stylesheets.
- `images/`: Centralized media assets.

### Student Contributions
The application is split into individual focus areas, allowing each student to manage their own modules independently:

- **Student 1**
  - `splash.html`: Introduction and welcome screen.
  - `volunteer.html`: Information on how to get involved and volunteer.
  - `content_ST1.html`: Topic-specific climate action content.

- **Student 2**
  - `home.html`: The main landing dashboard.
  - `table.html`: Tabular data representation and metrics.
  - `content_ST2.html`: Topic-specific climate action content.

- **Student 3**
  - `team.html`: Information about the project developers.
  - `feedback.html`: User feedback form and contact.
  - `content_ST3.html`: Topic-specific climate action content.

- **Student 4**
  - `profile.html`: User or organization profiles.
  - `sitemap.html`: Overview of the website's structure for easy navigation.
  - `content_ST4.html`: Topic-specific climate action content.

## 🛠️ How to Run Locally

Since this is a static website, no build steps, installations, or servers are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/d3mio/ClimateAction.git
   cd ClimateAction
   ```

2. **Open the application:**
   Simply double-click `index.html` or open it in your preferred web browser:
   ```bash
   open index.html
   ```
